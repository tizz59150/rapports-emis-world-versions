# Rapports Emis World : téléchargements

Installateurs du logiciel **Rapports Emis World** (rapports d'intervention Emis World).

➡️ **[Télécharger la dernière version](../../releases/latest)**

| Système | Fichier |
|---|---|
| Windows 10 / 11 | `Installer-Rapports-Emis-World.exe` : double-clic, pas de droits administrateur. Si SmartScreen s'affiche : *Informations complémentaires → Exécuter quand même*. |
| Mac (puces Apple) | `Rapports-Emis-World-Mac.dmg` : glisser l'application dans *Applications*, puis la première fois *clic droit → Ouvrir*. |

Une fois installé, le logiciel propose lui-même les nouvelles versions au démarrage. Les rapports déjà saisis sont conservés.
